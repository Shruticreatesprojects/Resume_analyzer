# Requirements
## Functional Requirements

- User can upload resume (PDF/DOCX).
- System parses and analyzes the resume.
- AI extracts skills, education, and experience.
- User can upload a job description.
- System compares resume with the job description.
- Displays ATS score and analysis report.
- Shows missing skills and improvement suggestions.
- Generates career recommendations.

## Non-Functional Requirements

- Easy-to-use and responsive UI.
- Fast resume processing.
- Secure file handling.
- Accurate AI analysis.
- Cross-browser compatibility.
- Reliable and scalable system.

📄 docs/workflow.md
# Workflow

1. User opens the application.
2. User uploads a resume.
3. User optionally uploads a job description.
4. Backend validates and processes the files.
5. AI extracts resume information.
6. System compares the resume with the job description.
7. ATS score and detailed analysis are generated.
8. Results are sent to the frontend.
9. User views the analysis, skill gaps, and recommendations.
